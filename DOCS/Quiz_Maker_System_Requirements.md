# AI小テストジェネレーター（AI Quiz Maker）要件定義書

## 1. プロジェクト概要

### 1.1 背景と目的
「過去問データベース（`kakomon-data-base`）」が画像切り出しによる大問・定期テスト作成に特化しているのに対し、本システムは**テキスト・構造化データをベースとした日常的な小テスト（確認テスト・英単語/漢字・計算ドリル・一問一答など）の高速作成**に特化したWebアプリケーションである。

PDFや既存のCSV/JSONを取り込むだけで、Gemini APIが問題を自動抽出・構造化し、レイアウト崩れのないA4/B4小テストをワンクリックで印刷・PDF化できる環境を提供する。

---

## 2. ユーザーペルソナと利用シーン

* **利用者**: 塾講師、学校教員、教材作成スタッフ
* **利用シーン**:
  1. **授業前**: 市販問題集や過去テストのPDFを読み込ませ、今日の授業で実施する10分間の確認テスト（10問〜20問）を3分で作成。
  2. **生徒別個別課題**: 苦手単元や特定レベルの問題をCSVからピックアップし、印刷して配布。
  3. **教材ストック**: 一度AIでデータ化した問題をCSV/JSON形式でローカルまたはクラウドに蓄積。

---

## 3. コア機能要件

### A. データ入力・AI解析機能
1. **PDFインポート & AI自動解析**
   - PDFファイル（または問題プリント画像）をアップロード。
   - **Google Gemini API (Gemini 2.0 Flash)** を利用し、PDFから設問・選択肢・解答・解説・配点を一括解析・構造化。
   - 解析結果をリアルタイムでテーブル形式にマッピング。
2. **CSV / JSON インポート・エクスポート**
   - 外部で作成した問題CSV、または過去にエクスポートしたJSONをドラッグ＆ドロップで即時読み込み。
   - AI解析した問題データをCSV/JSONとして一括ダウンロード。
3. **プロンプトテンプレート切り替え**
   - 「一問一答（理社）」「語句・漢字・英単語」「4択選択式」「数学（数式・小問）」「穴埋め問題」など、教材種別に最適化された解析プロンプトを選択可能。

### B. 問題編集・管理機能（スプレッドシート風UI）
1. **インライン編集テーブル**
   - 抽出された問題文、選択肢、模範解答、解説、配点、単元名を画面上で直接修正可能。
2. **問題の取捨選択と並び替え**
   - チェックボックスによる採用/除外。
   - ドラッグ＆ドロップによる出題順の並び替え。
   - ランダム並び替え（シャッフル）機能。
3. **プレビュー即時連動**
   - 左側で問題データを編集すると、右側の用紙プレビューがリアルタイムに再レンダリング。

### C. 自動組版 & 印刷出力機能（Print-Ready）
1. **用紙レイアウトテンプレート**
   - **用紙サイズ**: A4（標準）、B4、A3対応（縦向き / 横向き）。
   - **段組み**: 1段組み、2段組み、3段組み（語句・英単語用）。
   - **用紙構成**:
     - 氏名欄、日付欄、得点欄（合計点自動計算）。
     - 各問題の解答記入枠（四角枠 / アンダーライン / 記号選択欄）。
2. **問題編 / 解答・解説編の同時出力**
   - 「問題用紙」と「解答・解説用紙」をタブ切り替え、または同時印刷。
   - 解答編には正解を赤字・太字で印字し、解説文を表示。
3. **CSS Print最適化（ズレのない印刷）**
   - ブラウザ標準の印刷ダイアログ（`Ctrl+P` / `Cmd+P`）から、改ページ位置やマージンが完全に計算された高品質なPDF出力。

## 4. データモデル定義

### 4.1 問題単位（QuizItem）
```typescript
export interface QuizItem {
  id: string;                  // 一意なID (UUID)
  questionNumber: number;      // 出題番号 (1, 2, 3...)
  category?: string;           // 教科 (数学, 英語, 理科, 社会, 国語)
  field?: string;              // 単元・分野
  questionText: string;        // 問題文 (LaTeX数式記法対応)
  choices?: string[];          // 選択肢 (4択問題等の場合)
  answer: string;              // 模範解答
  explanation?: string;        // 解説文
  points: number;              // 配点 (例: 5)
  formatType: 'short_answer' | 'multiple_choice' | 'fill_in_the_blank' | 'term';
}
```

### 4.2 テスト設定（QuizSheetSettings）
```typescript
export interface QuizSheetSettings {
  title: string;               // テストタイトル (例: 第3回 中2数学 連立方程式確認テスト)
  subTitle?: string;           // サブタイトル (例: 目標点: 80点 / 制限時間: 15分)
  paperSize: 'A4' | 'B4';      // 用紙サイズ
  orientation: 'portrait' | 'landscape'; // 向き
  columnCount: 1 | 2 | 3;      // 段組み
  showAnswerSpace: boolean;    // 解答欄を用紙内に埋め込むか
  showPoints: boolean;         // 各問の配点表示有無
  fontSize: 'small' | 'medium' | 'large';
}
```

### 4.3 入出力CSVフォーマット標準
```csv
番号,形式,問題文,選択肢(カンマ区切り等),解答,解説,配点,教科,単元
1,short_answer,日本の首都はどこか。,,東京,日本の首都は東京都です。,5,社会,地理
2,multiple_choice,光合成を行う細胞小器官はどれか。,"核,葉緑体,ミトコンドリア,液胞",葉緑体,植物の葉緑体で光合成が行われます。,5,理科,生物
```

## 5. 技術スタック

| レイヤー | 選定技術 | 選定理由 |
| :--- | :--- | :--- |
| **フレームワーク** | **Next.js (App Router) + TypeScript** | 高速なレンダリング、API RoutesによるGemini APIの安全な隠蔽 |
| **スタイリング** | **Tailwind CSS** | `@media print` を用いた厳密な用紙CSS組版が容易 |
| **アイコン** | **Lucide React** | 軽量で統一感のあるモダンUI |
| **AI エンジン** | **Google Gemini API (Gemini 2.0 Flash)** | PDFのネイティブ入力、高精度な日本語構造化JSON抽出、超高速レスポンス |
| **CSV パーサー** | **Papaparse** | 日本語文字コード（Shift-JIS/UTF-8）のパース、高速処理 |
| **数式レンダラ** | **KaTeX** (任意) | 数学の分数・平方根・累乗を綺麗に表示する場合に利用 |
| **データ永続化** | **Local Storage / IndexedDB** | 最初はサーバーレス・ログイン不要でサクサク動作。将来的にSupabase拡張可能 |

## 6. 非機能要件・UI/UX原則

1. **ゼロ・インストール & 待ち時間ゼロ**:
   - 会員登録なしでも即座にブラウザ上で動くクライアント完結の軽快さ。
2. **完全なWYSIWYG（見たまま印刷）**:
   - 画面の右側プレビューと、実際に印刷・PDF化された紙面のレイアウト・改ページ位置が完全一致すること。
3. **キーボード操作性**:
   - テーブル内の配点や問題文をTabキーや矢印キーで連続編集できる操作性。
