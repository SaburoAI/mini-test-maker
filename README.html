Official Documentation & User Manual

AI ミニテストメーカー (Mini Test Maker)

学校・学習塾・各種教育機関における「毎日の小テスト作りに追われる時間」を極限まで削減。 20分で完結する日常小テスト（確認テスト・朝テスト・単元チェック）を最短工数で作成・印刷・スプレッドシート連携するWebアプリケーションです。

1 システムの概要と特長

小テスト作成の最大の課題は、「問題文を手打ちする手間」「レイアウト調整に奪われる時間」「配点計算の煩雑さ」です。本アプリはこれらの課題を以下のコア思想によって解決します。

🎯 選択と微調整だけに集中

白紙から打つのではなく、AIが蓄積した問題ストックから自動充填し、気になる箇所だけを「スワップ」「手直し」「削除」します。

📐 A4縦2段組 WYSIWYG

画面右側のプレビューがそのまま紙面に印刷。生徒用（解答下線）と教師用（赤字解答・解説枠）をワンクリックで切り替え可能です。

🧮 100点スマート配点エンジン

問題を削除・追加・差し替えても、ボタンひとつで均等自動割り付け。余り点数も自動按分し、ジャスト100点をキープします。

🔤 TeX数式 ＆ SVGベクター図形

数式は LaTeX / KaTeX でレンダリング。幾何図形・グラフは SVG ベクターコードとして保持するため、拡大印刷しても線が劣化しません。

⚡ トークン最小化「Mini-JSON」

外部LLM（ChatGPT, Claude, Gemini）の消費トークン数とレスポンス時間を40〜50%削減する専用の短縮キースキーマを採用。

🎧 英語リスニング & 放送台本

音声ファイル再生に加え、放送スクリプトを設定可能。生徒用紙では非表示、模範解答付きプリントにのみ台本枠が印字されます。

2 クイックスタート（導入・起動方法）

Node.js がインストールされた環境であれば、以下の3ステップですぐに起動できます。

Bash / PowerShell 
# 1. リポジトリのディレクトリへ移動
cd mini-test-maker

# 2. 依存パッケージのインストール
pnpm install
# 3. ローカル開発サーバーの起動
pnpm dev

起動後、ブラウザで http://localhost:3000 にアクセスすると、初期データが読み込まれた状態で即座にテスト作成を開始できます。

コマンド 用途・説明
pnpm dev 開発モードでローカルサーバーを起動（変更が即時反映されます）
pnpm build 本番環境向けの最適化ビルドを生成
pnpm start ビルド済みの本番サーバーを起動
pnpm lint ESLint によるコード解析と構文チェックを実行

3 画面構成と基本ワークフロー

本システムは、視線と作業の流れに沿った左から右へ流れる3カラム（ペイン）構造を採用しています。

STEP 1 問題を探す（プール）
  • 学年・教科・単元での絞り込み
  • #タグフィルター（#頻出・#基礎）
  • あいまいキーワード検索
  • 自作問題の新規作成
  • 外部AI用「類題生成プロンプト」作成
  • 「+大問1」「+大問2」へ即座投入
STEP 2 テスト編成（スロット）
  • ⚡️ 空枠への一括自動充填
  • 🧮 100点自動配点エンジン
  • 🔄 スワップ（同単元の別候補に置換）
  • ✏️ インライン手直し（文・解答・配点）
  • 🗑️ 削除（配点即時再計算）
  • ✂️ 大問分割 / 🔗 設問マージ
  • ✨ 大問タイトルのAI自動推論
STEP 3 完成プレビュー & 印刷
  • A4縦2段組 リアルタイムWYSIWYG
  • 👨‍🎓 生徒用問題 / 👨‍🏫 模範解答付 切替
  • 解答下線レイアウト最適化（横/縦/同一行）
  • 下線幅の微調整（＋/ー）
  • プレビュー上でのダイレクト編集
  • 🖨️ ワンクリック印刷 / PDF出力連動

4-1 STEP 1: 問題を探す・ストックする（問題プール）

蓄積された問題バンクから目的の問題を素早く探し出し、テストに投入します。

1. 多階層フィルター & タグ絞り込み

  • 学年（Grade）: 「中1」「中2」「高1」など対象学年を選択。
  • 教科・ジャンル（Genre）: 「数学」「理科」「英語」などのタブで切り替え。
  • 単元（Topic）: メイン単元ごとの問題数がバッジ表示され、クリックで単元抽出。
  • タグ（#Tags）: 「#頻出」「#基礎」「#計算力」「#入試過去問」などのタグをクリックしてAND/OR検索。

2. あいまい検索（Fuzzy Search）

上部の検索窓に文字を入力すると、問題文、サブ論点、タグ、模範解答を対象に高速インクリメンタル検索が行われます。

3. 問題カードの主要アクション

  • 「+ 大問1」「+ 大問2」ボタン: 該当の大問の末尾にワンタップで追加。
  • 「+ 新大問として追加」: この問題を第1問とする新しい大問セクションを即座に作成。
  • 「👁️ 解答表示」: カード上で正解と解説のプレビューをオン/オフ。
  • 「✨ 類題」ボタン: この問題の構造をもとに、ChatGPTやClaudeで類題を作成するためのプロンプトをワンクリック生成。
  • 「小問 / 枝問」ボタン: （1）（2）（3）などの枝問を含む問題から、必要な小問だけを間引いて選択できる「枝問エディタ」を起動。
  • 「✏️ 編集」: 問題文、解答、解説、配点、タグ、SVG図形、画像、リスニング音声台本を編集。
  • 「🗑️ 削除」: プールから削除。誤って削除しても、画面下のトーストからワンクリックで「元に戻す（復元）」が可能です。

4-2 STEP 2: テストを編成・調整する（スロット管理）

テスト全体の大問枠組み、問題スロットの配置、配点の自動均等計算を行います。

1. ⚡️ 一括自動充填

まだ空きがあるスロットや大問枠に対し、選択中のジャンルに合致する問題をプールから自動配備します。

2. 🧮 スマート配点エンジン（100点自動調整）

総設問数に応じて、合計がジャスト100点になるよう自動均等配分します。余りが出た場合は難易度の高い問題へ自動按分されます。

🟩 100 / 100点 (ジャスト一致) 🟨 92 / 100点 (点数不足) 🟥 108 / 100点 (点数超過)

3. 各問題スロットのアクション

  • 🔄 スワップ（差し替え）: 同一単元・タグを持つ別の問題候補にワンクリック置換。
  • ✏️ インライン編集: テスト用紙限定で問題文や配点を直接手直し。
  • 🗑️ 削除: スロットから問題を除外。配点は自動的に再計算が促されます。
  • ✂️ 大問分割（Split）: その問題の位置で大問を2つに切り離し。
  • 🔗 設問マージ: 連続する小問同士を1つの大問・長文問題枠に統合。
  • ⬆️ / ⬇️ 並び替え: 出題順を上下に入れ替え。

4. 大問セクションのカスタマイズ

  • 大問タイトル編集: 「大問１　2次関数の変域」など自由に編集。
  • ✨ AIタイトル推論: 収録されている問題の内容から、最適な大問名をワンクリックで自動推論。
  • 📄 ページ配置指定: 「P.1」「P.2」「新ページとして追加」により印刷時の改ページ位置を制御。
  • ↩️ Undo（元に戻す）: 直前の操作はヘッダーまたは Ctrl+Z で巻き戻し可能。

4-3 STEP 3: 完成プレビュー・印刷（WYSIWYG & 印刷エンジン）

A4縦2段組（実寸比率 210mm × 297mm）で実際のテスト用紙をリアルタイム確認します。

1. 表示モードの切り替え

👨‍🎓 生徒用問題用紙

問題文、図形、配点、解答記入用の下線（アンダーライン）を表示。リスニング放送台本は自動非表示になります。

👨‍🏫 模範解答付用紙（教師・採点用）

解答下線に赤字で正解が印字され、各問に詳細な解説枠と配点が表示。リスニング放送原稿も印字されます。

2. 解答欄レイアウトの自動＆手動最適化

レイアウト形式 適した出題パターン 特徴
inline（横並び短答） 記号選択、短い数値、英単語 正解の文字数に応じた下線幅を自動計算。紙面高さをコンパクトに抑制
stacked（1行記述） 英作文、数学の途中式、論述記述 生徒が余裕を持って記入できるよう、各問ごとに十分な記入スペースを確保
same-line（問題同一行） 1行で完結する計算問題、漢字 問題文の真横の余白に解答下線を配置し、極限まで行数を節約

3. 解答欄の微調整ツール

  • 下線幅の微調整（＋ / ー ボタン）: 各問題のツールバーから下線長さを自由に伸縮可能。
  • 揃え位置の変更: 左寄せ、中央揃え、右寄せを切り替え可能。
  • 2列グリッド（英単語モード）: 単語テストや計算ドリル向けに、設問を左右2列にレイアウト。

5 外部AI連携とデータインポート / エクスポート

ChatGPT / Claude / Gemini Web版などの生成AIを活用し、教材や過去問テキストから一撃で小テストデータを作成できます。

Mini-JSON 仕様（トークン最小化短縮スキーマ）

外部LLMの生成トークン数とレスポンス時間を40〜50%削減する短縮キースキーマです。

Mini-JSON 配列の例 (JSON) 
[
  {
    "g": "数学",
    "t": "円周角の定理",
    "st": "中心角と円周角の関係",
    "tg": ["頻出", "図形", "中3"],
    "d": 2,
    "s": 90,
    "q": "下の図において、点\\( O \\)を中心とする円の円周上に点\\( A, B, C \\)がある。\\( \\angle BAC = 42^\\circ \\)のとき、\\( \\angle BOC \\)の大きさを求めよ。",
    "a": "\\( \\angle BOC = 84^\\circ \\)",
    "e": "円周角の定理より、中心角の大きさは円周角の大きさの2倍であるため、\\( 42^\\circ \\times 2 = 84^\\circ \\)。",
    "svg": "<svg viewBox='0 0 150 120'>...</svg>"
  }
]
キー 項目名 型 説明
gGenrestring教科・大ジャンル（数学, 英語, 理科 等）
tTopicstringメイン単元（二次方程式, 不定詞 等）
stSub-Topicstringサブ論点・解法パターン（解の公式, 名詞的用法 等）
tgTagsstring[]属性タグ（["頻出", "基礎", "定期テスト"] 等）
dDifficulty1 | 2 | 3難易度（1: 基礎, 2: 標準, 3: 発展）
sSecondsnumber目安解答秒数（小テストの時間積算に使用）
qQuestionstring問題文（LaTeX数式記法 \( ... \) に対応）
aAnswerstring模範解答
alAnswer Labelsstring[]?複数解答欄ラベル（["xの値", "yの値"] 等・省略可）
lyLayoutstring?解答欄レイアウト（inline, stacked, same-line・省略可）
eExplanationstring?模範解説（省略可）
svgSVG Figurestring?幾何図形・グラフのベクター座標コード（任意）
imgImage URLstring?問題画像のURLまたはローカルパス（任意）
audAudio URLstring?リスニング音声ファイルのURLまたはパス（任意）
asAudio Scriptstring?リスニング放送台本（生徒用紙では非表示、教師用紙に印字）

外部AI用コピペプロンプト標準テンプレート

以下のプロンプトをそのままChatGPT等のAIに貼り付けて指示を出してください。

AIプロンプト用指示文 (Markdown) 
以下の教材内容から、20分小テスト用の良問を抽出し、以下の短縮JSON配列形式（Mini-JSON）のみを出力してください。前置きや解説文は一切不要です。

[
  {
    "g": "教科",
    "t": "メイン単元",
    "st": "サブ論点",
    "tg": ["頻出", "基礎"],
    "d": 2,
    "s": 90,
    "q": "問題文（数式は \\( ... \\) で記述）",
    "a": "模範解答",
    "e": "解説",
    "svg": "<svg>...</svg>（図形問題の場合のみ・不要なら省略）"
  }
]

【作成条件】
1. 数式・記号・英文字変数は必ずLaTeX記法 \\( ... \\) を使用してください。
2. 難易度(d)は 1(基本), 2(標準), 3(発展) を設定してください。
3. 20分テストを想定し、目安解答秒数(s)を正確に見積もってください。

6 スプレッドシート連携とデータ保存

1. Googleスプレッドシート / Excel からの取込

ヘッダーの「取込 / インポート」をクリックし、「スプレッドシート / TSV」タブを選択。 表計算ソフトの行データをコピーして貼り付けるだけで一括インポートできます。

2. TSVエクスポート（スプレッドシートへ出力）

ヘッダーの「TSV出力」ボタンをクリックすると、現在のテスト問題（またはプール全体）がクリップボードにコピーされます。 スプレッドシートを開いて Ctrl+V を押すだけでテーブルとして貼り付けられます。

3. データの保存・呼出

  • ブラウザ自動保存: 作業中のデータは LocalStorage にリアルタイム保存されます。
  • プロジェクト内（data/）保存: ヘッダーの「保存・呼出」から名前を付けてJSONファイルとして保存・呼び出しが可能です。

7 数式・図形・マルチメディア記法

1. LaTeX数式記法（KaTeX）

インライン数式は \( ... \) で囲みます。

  • 二次方程式: \( 2x^2 + 5x - 1 = 0 \)
  • 解の公式: \( x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \)
  • 角度: \( \angle ABC = 75^\circ \)

2. SVGベクター図形

svg プロパティに <svg viewBox="0 0 160 120">...</svg> を指定します。 ベクター座標データとしてレンダリングされるため、印刷時にも線や文字が美しく鮮明に出力されます。

3. 英語リスニング音声 & 放送台本

aud に音声ファイルパス、as に放送台本テキストを設定。 生徒用プリントでは台本は完全に隠され、模範解答付き（教師用）プリントにのみ「放送台本枠」として印字されます。

8 印刷・PDF出力のベストプラクティス

Google Chrome または Microsoft Edge での印刷時に、最も綺麗な仕上がりを得るための推奨設定です。

印刷設定項目 推奨設定値 理由
送信先 PDFに保存 / お使いのプリンター PDFとして保存すればそのまま配布・保管可能
レイアウト 縦 A4縦2段組に最適化されています
用紙サイズ A4 用紙サイズ基準（210mm × 297mm）
余白 なし (推奨) アプリ側で厳密に15mmの印刷余白を自動確保しているため
倍率（拡大/縮小） 既定 (100%) 原寸で印刷
背景のグラフィック オン（チェック） 大問の網掛け背景や解答欄の罫線を出力するため
ヘッダーとフッター オフ（チェックを外す） URLや日時などのブラウザ余白印字を非表示にするため
💡
PDFファイル名の自動連動:
アプリ上で設定した「テスト名」がブラウザの印刷保存ダイアログのデフォルトファイル名に自動的に反映されます。保存時にファイル名を打ち直す必要がありません。

9 よくある質問 (FAQ)

Q. 印刷するとどうしても2ページ目にわずかにはみ出してしまいます。

ブラウザ印刷ダイアログの「余白」設定が「なし」になっているか確認してください。「既定」になっているとブラウザ側の余白が二重に付与され、改ページが発生することがあります。
また、問題スロットの解答欄レイアウトを stacked から inline または same-line に変更することで紙面高さを節約できます。

Q. 問題文の中の数式が表示されず、生の文字列のままになります。

数式が \( ... \) で囲まれているか確認してください。ドル記号 $ ... $ ではなくバックスラッシュ括弧を使用することで、安定してKaTeXレンダリングされます。

Q. ブラウザを閉じたりキャッシュを削除したらデータはどうなりますか？

ブラウザを閉じるだけではデータは保持されます（LocalStorage）。ただし、ブラウザ履歴・Cookieの全削除を行うと初期化されるため、大切なテストデータはヘッダーの「保存・呼出」からファイル保存するか、「JSON出力」でバックアップしておくことをお勧めします。
