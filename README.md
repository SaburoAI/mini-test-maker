## 1. システムの概要と特長

本アプリケーションは、学校や学習塾、教育現場における**「毎日の小テスト作りに追われる時間」を極限まで削減**するために設計された専用テスト作成ツールです。

### 🌟 コアバリュー & UX思想
1. **「人間の仕事は、AIが蓄積した問題を選択・調整することだけに絞る」**  
   白紙から問題文をタイピングする必要はありません。蓄積された問題プールからワンクリックで大問スロットへ自動充填し、気になる問題だけを「スワップ」「手直し」「削除」します。
2. **明確な3ステップUI構造**  
   左（問題プール）→ 中央（テスト編成）→ 右（A4完成プレビュー）の3ペイン構成により、思考を止めずにテストを組み上げられます。
3. **TeX数式 ＆ SVGベクター図形による高品質印字**  
   - 数式は LaTeX / KaTeX（`\( ... \)`）で美しくレンダリング。
   - 幾何図形・グラフ・座標軸は **SVGベクターコード** として保持。印刷時や高解像度ディスプレイでも一切劣化・ボケません。
4. **スマート配点エンジン（100点自動調整）**  
   設問を追加・削除・差し替えても、ボタンひとつで100点満点（または目標点）に均等自動配分。配点計算の手間をゼロにします。
5. **トークン消費を極限までケチる「Mini-JSON」**  
   ChatGPT / Claude / Gemini などの外部LLMから問題を出力させる際、生成トークン数とAPI待機時間を40〜50%削減する短縮キースキーマを採用しています。
6. **完全なA4用紙WYSIWYG ＆ 印刷連動**  
   画面右側のプレビューがそのまま紙面に印刷されます。生徒用（解答下線付き）と教師用（模範解答・解説・リスニング台本付き）をワンクリックで切り替え可能です。

## 2. クイックスタート（導入・起動方法）

### 前提条件
- Node.js 18.18.0 以上（Node.js 20+ 推奨）
- pnpm

### インストールと起動
```bash
# 1. リポジトリのディレクトリに移動
cd mini-test-maker

# 2. 依存パッケージのインストール
pnpm install
# 3. 開発サーバーの起動
pnpm dev
```

ターミナルに以下が表示されたら、ブラウザでアクセスします。
```text
  ▲ Next.js 16.3.4
  - Local:        http://localhost:3000
```

ブラウザで `http://localhost:3000` を開くと、初期データが読み込まれた状態で即座にテスト作成を開始できます。

### その他のコマンド
- `pnpm build` : 本番用ビルドを作成
- `pnpm start` : ビルドした本番サーバーを起動
- `pnpm lint`  : ESLintによる構文・型チェック

## 4. 詳細な利用手順

### STEP 1: 問題を探す・ストックする（問題プール）

画面左側のカラムでは、ストックされている問題バンクから目的の問題を素早く探し出し、テストに投入します。

1. **多階層フィルター & タグ絞り込み**
   - **学年（Grade）**: 「中1」「中2」「高1」などで絞り込み。
   - **ジャンル・教科（Genre）**: 「数学」「英語」「理科」などの教科タブで切り替え。
   - **単元（Topic）**: メイン単元ごとの問題数がバッジ表示され、クリックで対象単元に絞り込み。
   - **タグフィルター（#Tags）**: 「#頻出」「#基礎」「#計算力」「#入試過去問」などのタグをクリックしてAND/OR検索。
2. **あいまい検索（Fuzzy Search）**
   - 上部の検索窓にキーワードを入力すると、問題文・解説・サブ論点・タグを対象にインクリメンタルに高速検索されます。
3. **問題カードの操作**
   - **「+ 大問1」「+ 大問2」ボタン**: 該当の大問セクションの末尾にワンタップで追加。
   - **「+ 新大問として追加」ボタン**: この問題を第1問とする新しい大問セクションを即座に作成。
   - **「👁️ 解答表示」**: 問題カード上の模範解答と解説の表示/非表示を個別にプレビュー。
   - **「✨ 類題」ボタン**: この問題の構造をもとに、外部AI（ChatGPT等）で類題を作成するための最適化プロンプトをワンクリック生成・コピー。
   - **「小問 / 枝問」ボタン**: （1）（2）（3）などの小問を含む問題の場合、必要な小問だけを間引いて選択できる「枝問エディタ」を起動。
   - **「✏️ 編集」**: 問題文、解答、解説、配点、タグ、SVG図形、画像、リスニング音声台本を編集。
   - **「🗑️ 削除」**: 問題プールから削除。誤って削除した場合も画面下部のトーストからワンクリックで「元に戻す（復元）」が可能。
4. **「+ 新規作成」ボタン**
   - プール上部の「+ 新規作成」ボタンから、自作の問題をゼロから登録できます。

---

### STEP 2: テストを編成・調整する（スロット管理）

画面中央のカラムでは、テスト全体の大問構成、問題の配置、配点の自動均等計算を行います。

1. **⚡️「自動充填」ボタン**
   - まだ空きがある大問スロットや、選択ジャンルに合致する問題をプールから自動的にバランスよく充填します。
2. **🧮「配点再計算」ボタン（スマート配点エンジン）**
   - 総設問数に応じて、合計がジャスト**100点**になるよう自動配分します。
   - 余りが出た場合は難易度の高い問題や配点比重の高い問題へ自動按分。
   - 上部のステータスゲージで整合性をひと目で把握可能：
     - 🟩 **緑色バッジ（100 / 100点）**: 完璧に一致
     - 🟨 **黄色バッジ（例: 92 / 100点）**: 点数不足
     - 🟥 **赤色バッジ（例: 108 / 100点）**: 点数超過
3. **大問セクションのカスタマイズ**
   - **タイトル直接編集**: 「大問１　2次関数の変域」など、大問ヘッダーを自由に書き換え。
   - **✨ AI大問タイトル自動推論**: 収録されている問題の内容を分析し、最適な大問タイトルをワンクリックで自動推論して設定。
   - **🔗 大問マージ**: 次の大問と1つに合体（長文総合問題化）。合体後は「解除」ボタンで元に戻せます。
   - **📄 ページ配置指定**: 「P.1」「P.2」「新ページとして追加」で、印刷時のページ跨ぎをコントロール。
4. **各問題スロットの直感アクション**
   - **🔄 スワップ（差し替え）**: 同じ単元・タグを持つ別の問題候補にワンクリックで入れ替え。
   - **✏️ 編集**: このテスト用紙限定で問題文や数式、配点をインライン手直し。
   - **🗑️ 削除**: スロットから問題を除外。削除と同時に配点再計算が促されます。
   - **✂️ 大問分割（Split）**: その問題の位置でセクションを2つに分割。
   - **🔗 設問マージ**: 連続する小問同士を1つの問題枠に統合。
   - **⬆️ / ⬇️ 並び替え**: 出題順を上下に移動。
5. **↩️ Undo（元に戻す）**
   - スワップや削除、並び替えなどの操作は、ヘッダーまたは画面上の「元に戻す」ボタン（`Ctrl+Z`）でいつでも巻き戻せます。

---

### STEP 3: 完成プレビュー・印刷（WYSIWYG & 印刷エンジン）

画面右側のカラムでは、A4縦2段組（実寸比率 210mm × 297mm）で実際のテスト用紙をリアルタイム表示します。

1. **表示モードの切り替え（ヘッダーで切り替え）**
   - **👨‍🎓 生徒用問題用紙**:
     - 問題文、図形、配点、解答記入用の下線（アンダーライン）を表示。
     - リスニング問題の場合、放送用スクリプトは自動的に隠されます。
   - **👨‍🏫 模範解答付用紙（教師・採点用）**:
     - 解答欄に**赤字**で正解が印字されます。
     - 各問の下に詳しい解説枠を表示。
     - リスニング問題の放送台本（スクリプト）が教師向けに印字されます。
2. **解答欄レイアウトの自動＆手動最適化**
   - **`inline`（横並び短答）**: 記号問題や短い数式・語句に適した下線。文字数から最適な下線幅を自動計算。
   - **`stacked`（1問1行記述）**: 英作文や数学の途中式、記述論述に適した十分な解答スペースを確保。
   - **`same-line`（問題文同一行）**: 問題文の右端に短答下線を配置し、紙面高さを節約。
   - **下線幅の微調整（＋/ー）**: 各問題のツールバーにあるボタンで、下線長さを自由に伸縮可能。
   - **配置位置（左 / 中 / 右）**: 解答下線の揃え位置を変更可能。
   - **2列グリッド（英単語モード）**: 単語テストや計算ドリルなど、左右2列に設問を並べて紙面を有効活用。
3. **プレビュー画面からのWYSIWYG操作**
   - 用紙上の問題にマウスを重ねると操作ツールバーが現れ、プレビューを見ながら直接スワップ・編集・削除・並び替えが可能です。
4. **ズームコントロール**
   - 右上の拡大（Zoom In）・縮小（Zoom Out）・原寸（100%）・用紙全体表示ボタンで、作業環境に合わせた最適なサイズで紙面を確認できます。
5. **🖨️ 印刷 & PDF出力**
   - ヘッダーの「印刷」ボタン、またはブラウザの `Ctrl+P`（Mac: `Cmd+P`）を押すと、即座に印刷ダイアログが開きます。
   - **用紙タイトル連動**: ブラウザのPDF保存ダイアログにおいて、入力したテスト名が初期ファイル名として自動設定されます。

## 5. 外部AI連携とデータインポート / エクスポート

外部の生成AI（ChatGPT, Claude, Gemini Web版など）と連携することで、手持ちの教材テキストや過去問PDFから瞬時に問題データを生成し、本アプリに取り込むことができます。

### Mini-JSON 仕様（トークン最小化短縮スキーマ）

外部AIの出力トークン数を極限まで節約し、レスポンス速度とコスト効率を最大化する短縮キー仕様です。

```json
[
  {
    "g": "数学",
    "t": "円周角の定理",
    "st": "中心角と円周角の関係",
    "tg": ["頻出", "図形", "中3"],
    "d": 2,
    "s": 90,
    "q": "下の図において、点\\( O \\)を中心とする円の円周上に点\\( A, B, C \\)がある。\\( \\angle BAC = 42^\\circ \\)のとき、\\( \\angle BOC \\)の大きさを求めよ。",
    "a": "\\( \\angle BOC = 84^\\circ \\)",
    "e": "円周角の定理より、中心角の大きさは円周角の大きさの2倍であるため、\\( 42^\\circ \\times 2 = 84^\\circ \\)。",
    "svg": "<svg viewBox='0 0 150 120' class='w-32 h-24 mx-auto'>...</svg>"
  }
]
```

#### キー定義一覧

| キー | 項目名 | 型 | 説明・役割 |
| :--- | :--- | :---: | :--- |
| `g` | Genre | `string` | 教科・大ジャンル（`数学`, `英語`, `理科`, `社会`, `国語` 等） |
| `t` | Topic | `string` | 大単元・メイン論点（`二次方程式`, `円周角の定理`, `不定詞` 等） |
| `st` | Sub-Topic | `string` | サブ論点・解法パターン（`解の公式`, `名詞的用法` 等） |
| `tg` | Tags | `string[]` | 属性タグ（`["頻出", "基礎", "ミス多発", "定期テスト"]` 等） |
| `d` | Difficulty | `1 \| 2 \| 3` | 難易度（`1`: 基礎, `2`: 標準, `3`: 発展） |
| `s` | Seconds | `number` | 目安解答秒数（小テストの自動時間積算に使用） |
| `q` | Question | `string` | 問題文（TeX数式記法 `\( ... \)` に完全対応） |
| `a` | Answer | `string` | 模範解答 |
| `al` | Answer Labels | `string[]?` | 複数解答欄ラベル（`["xの値", "yの値"]` 等・省略可） |
| `ly` | Layout | `string?` | 解答欄レイアウト（`inline`, `stacked`, `same-line`・省略可） |
| `e` | Explanation | `string?` | 模範解説（省略可） |
| `svg`| SVG Figure | `string?` | 幾何図形・グラフのベクター座標コード（任意） |
| `img`| Image URL | `string?` | 問題画像のURLまたはローカルパス（任意） |
| `aud`| Audio URL | `string?` | リスニング音声ファイルのURLまたはローカルパス（任意） |
| `as` | Audio Script | `string?` | リスニング放送台本（生徒用紙では非表示、教師用紙に印字） |

### 外部AI用プロンプト標準テンプレート

ChatGPTやClaude、Geminiのプロンプト入力欄に以下をそのままコピペし、末尾に教材テキストや単元名を貼り付けてください。

```markdown
以下の教材内容から、20分小テスト用の良問を抽出・作成し、以下の短縮JSON配列形式（Mini-JSON）のみを出力してください。挨拶やコードブロック（```）以外の前置き・解説文は一切不要です。

[
  {
    "g": "教科（例: 数学）",
    "t": "メイン単元（例: 平方根）",
    "st": "サブ論点（例: 分母の有理化）",
    "tg": ["頻出", "計算力"],
    "d": 1,
    "s": 60,
    "q": "問題文（数式は \\( ... \\) で記述）",
    "a": "模範解答",
    "e": "わかりやすい解説",
    "svg": "<svg>...</svg>（幾何図形問題の場合のみ・不要なら省略）"
  }
]

【作成条件】
1. 数式・記号・アルファベット変数は必ずLaTeX記法 \\( ... \\) を使用してください。
2. 難易度(d)は 1(基本), 2(標準), 3(発展) のいずれかを設定してください。
3. 制限時間20分を意識し、1問あたりの目安解答秒数(s)を正確に見積もってください。
```

### スプレッドシート（TSV）連携

GoogleスプレッドシートやExcelとの双方向コピペに対応しています。

1. **インポート（取込）**:
   - ヘッダーの「取込 / インポート」をクリック。
   - 「スプレッドシート / TSV」タブを選択。
   - スプレッドシートのセル範囲（ヘッダー行: `教科`, `メイン単元`, `サブ論点`, `難易度`, `所要秒数`, `問題文`, `解答`, `解説`）をコピーし、テキストエリアにそのまま貼り付けて「取り込む」をクリック。
2. **エクスポート（出力）**:
   - ヘッダーの「TSV出力」をクリックすると、現在のテスト問題（またはプール全体）がクリップボードにコピーされます。
   - スプレッドシートを開いて `Ctrl+V` を押すだけで、綺麗なテーブルとして貼り付けられます。

### データ保存・呼出（LocalStorage & data/ 保存）

- **ブラウザ自動保存**:
  - 作業中の問題プール、テスト編成、設定内容はブラウザの `LocalStorage` にリアルタイムで自動保存されます。ブラウザを誤って閉じても作業内容は失われません。
- **プロジェクトローカル保存（`data/` ディレクトリ）**:
  - ヘッダーの「保存・呼出」ボタンをクリック。
  - 作成したテストセットや問題バンクに名前をつけて、プロジェクト内の `data/` フォルダへJSONファイルとして永続保存・呼出が可能です。

## 6. 数式・図形・マルチメディア記法

### 1. LaTeX 数式記法（KaTeX）
インライン数式は `\( ... \)` で囲みます。
- 二次方程式: `\( ax^2 + bx + c = 0 \)`
- 分数: `\( \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \)`
- 角度・度数: `\( \angle ABC = 60^\circ \)`
- 連立方程式や行列、ギリシャ文字（`\( \alpha, \beta, \theta, \pi \)`）にも完全対応。

### 2. SVG ベクター図形
幾何図形や関数グラフは、`<svg viewBox="...">` タグをそのまま `svg` プロパティに埋め込みます。
```html
<svg viewBox="0 0 160 120" class="w-36 h-28 mx-auto">
  <circle cx="80" cy="60" r="50" fill="none" stroke="#1e293b" stroke-width="2" />
  <line x1="30" y1="60" x2="130" y2="60" stroke="#0284c7" stroke-width="2" />
  <text x="80" y="55" font-size="12" text-anchor="middle">r = 5cm</text>
</svg>
```
解像度に依存しないベクター形式のため、拡大印刷しても線がぼやけず、教科書品質の鮮明な印字が得られます。

### 3. 画像・イラスト（`img`）
理科の実験器具や地理の地図、英語の場面イラストは、`img` プロパティにパス（例: `/images/map.png`）または画像URLを指定して表示できます。

### 4. 英語リスニング音声 & 放送台本（`aud`, `as`）
- `aud`: 音声ファイル（MP3等）のパスやURLを指定すると、プレビュー上で再生コントローラーが表示されます。
- `as`: 放送台本テキストを設定すると、生徒用プリントでは非表示になり、模範解答付き（教師用）プリントにのみ「放送台本枠」として綺麗に印字されます。

### よくある質問（FAQ）

#### Q1. 印刷すると2ページ目にわずかにはみ出してしまいます。
**A.** 以下の調整をお試しください：
1. ブラウザ印刷設定の**「余白」が「なし」**になっているか確認してください。
2. 問題数が多すぎる場合は、Step 2 で配点や設問数を見直すか、問題スロットのツールバーで「解答欄レイアウト」を `stacked` から `inline` または `same-line` に変更して行数を節約してください。
3. 大問を「2ページ目」に明示的に配置して、綺麗な2枚組テストとして編成することも可能です。

#### Q2. 問題文の中の数式がうまく表示されません。
**A.** 数式が `\( ... \)` で囲まれているか確認してください。ドル記号 `$ ... $` ではなく、バックスラッシュ括弧 `\( ... \)` を使用することで、他の記号との誤判定を防ぎ安定してKaTeXレンダリングされます。

#### Q3. ブラウザのキャッシュをクリアするとデータは消えますか？
**A.** `LocalStorage` をクリアするとブラウザ保存データは初期化されます。大切なテストセットや問題バンクは、ヘッダーの「保存・呼出」からファイル保存しておくか、「JSON出力」または「TSV出力」でバックアップしておくことを推奨します。
